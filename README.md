# StudyLog · 个人日常记录

一款轻量化个人日常记录 Web 网站，主打 **生活化记录、每日复盘、学习管理、日程规划** 四大核心体系。全程无社交、无广告、无推荐信息流，专注服务个人记录留存、数据复盘。

> **两种模式**
> - **公开页**（`/`）：只读，朋友浏览你的日记，页面上没有任何编辑控件
> - **写作台**（`/write`）：你自己用。**保存即同步到云端**，本机留一份缓存所以断网也能写；没令牌的人打开只会看到锁屏
>
> 日记以云端（Cloudflare D1）为准，换设备打开写作台就是同一份数据。
> 写入权限由服务端校验令牌，别人改不了你的内容。部署方法见 **[DEPLOY.md](DEPLOY.md)**。

## 功能概览

### 每日日记
- 富文本日志记录（文字、换行、简单标记）
- 8 种心情标签（开心、平淡、疲惫、焦虑、充实等），自动生成情绪曲线
- 每日复盘模板（今日完成 / 今日不足 / 明日计划）
- 本地图片上传插入
- 日历视图高亮标记，左右切换月份
- 关键词搜索、心情筛选
- 日志置顶、随手便签

### 学习打卡
- 学习台账记录（科目、内容、时长）
- 手动录入时长，自动累计日/周/月，生成柱状图
- 每日任务管理（添加、勾选、备注原因）
- 一键打卡签到，连续天数统计
- 书籍管理（书名、作者、进度、笔记、摘抄）
- 技能清单（练习进度、掌握程度、感悟）
- 内置专注计时器（正计时 / 倒计时）

### 日程规划
- 每周日程表（周一到周日独立编辑）
- 自定义时段（时间、活动）
- 当前时段自动高亮

### 目标清单
- 年度/季度目标管理（名称、截止日期、进度、备注）
- 进行中 / 已完成分区展示
- 一键标记完成，进度条可视化

### 数据仪表盘
- 全站数据聚合面板
- 核心统计卡片（日记数 / 学习时长 / 打卡天数 / 进行中目标）
- 今日概览（日记 / 学习 / 任务）
- 趋势图表（学习 / 情绪）

### 云端自动同步
- 打开写作台自动从云端读取已有日记
- 保存 / 删除即时同步，无需手动「发布」
- 断网可继续写，联网后自动补传
- 右上角状态徽标（已同步 / 同步中 / 仅本地 / 失败可重试）
- 可在设置里一键关闭，退回纯本地模式

### 系统设置
- 浅色 / 深色主题一键切换
- 数据手动备份导出 / 导入恢复
- 一键清除所有数据（含二次确认）
- 本地存储用量统计

## 快速开始

### 本地使用
直接双击 `write.html` 在浏览器打开即可（写作台在本地模式下无需任何服务器）。首次会看到锁屏，点「没有令牌？仅本地使用」即可进入 —— 这种模式下数据只存在本机。

### 部署上线
推荐 **Cloudflare Pages + D1**，免费额度足够个人使用，且能实现「只有我能写、朋友只能看」。

完整步骤见 **[DEPLOY.md](DEPLOY.md)**，大致是：

1. Cloudflare 建 D1 数据库，执行 `schema.sql` 建表
2. Pages 连接本仓库，构建命令留空、输出目录填 `/`
3. 给 Pages 项目绑定 D1，变量名必须是 `DB`
4. 配置环境变量 `ADMIN_TOKEN`（你的写作暗号）
5. 重新部署，在写作台 `/write` 输入暗号解锁 —— 之后写的每一篇都会自动同步

**只想要纯本地版？** 不绑定 D1 也能部署，写作台照常可用，只是公开页读不到数据。

**其他静态平台**（GitHub Pages / Vercel / Netlify / Nginx）：`write.html` 写作台能正常工作，但公开页与 `/api/*` 依赖 Cloudflare Pages Functions，在这些平台上不可用。

## 设计理念

- **极简留白** — 低饱和度柔和配色，护眼舒适
- **傻瓜化操作** — 一键新增、一键查看、一键统计
- **高私密性** — 数据存在你自己的 Cloudflare 数据库里，写入受服务端令牌保护；本机只是一份缓存
- **零干扰** — 无广告、无社交、无推荐流
- **全平台适配** — 移动端底部导航、桌面端侧边导航，严格响应式

## 数据流

```
写作台保存  →  (1) 写入本机缓存，界面立刻更新
            →  (2) 异步推送到你的 D1  →  朋友刷新公开页即可看到
打开写作台  →  读本机缓存先渲染，再向云端对一次（拉回别处写的、补传本地新写的）
```

**冲突怎么处理**：同一天两边都有内容时，以 `updatedAt` 较新的为准；本机的图片数据不会被云端覆盖掉。

## 隐私说明

- 写作台无需注册、无需手机号；数据存在**你自己的** Cloudflare D1 数据库里
- 写日记会自动同步到你的 D1；本机浏览器留一份缓存，断网时照常可写，联网后自动补传
- 不绑定 D1 也能用 —— 那种情况下是纯本地模式，数据只存在浏览器里
- 公开页对整个互联网可读，但带有 `noindex`，不会被搜索引擎收录
- 写入权限由服务端校验令牌，访客无法修改或删除你的内容
- 图片目前以 Base64 编码本地存储，暂不同步（后续接入 R2 对象存储后支持）
- 支持手动导出备份文件
- 不收集任何个人信息，无第三方统计或跟踪代码
